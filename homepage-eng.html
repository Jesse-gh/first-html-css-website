Welcome to my website!

This website is my first HTML and CSS project. The main purpose of this webpage is to document and explain how this website itself was built. This website was originally created for the "Explore the fundamentals of HTML and CSS" course at the South Eastern University of Applied Sciences, but the idea is also to use this in my portfolio.

Project details summarized:

  • Technologies: It is built using only HTML and CSS languages. None of more advanced technologies were used purposefully.
  • Responsive Design: The website is fully responsive, meaning it scales dynamically and is designed to work on both desktop computers and mobile devices.
  • The website has six pages in total:
    • A homepage in English (this page).
    • The aforementioned homepage translated into Finnish.
    • A more detailed and technical version of the English homepage aimed at IT professionals or those with an IT background.
    • The aforementioned detailed page translated into Finnish.
    • A Media page in English which has an image gallery and an embedded YouTube video.
    • The aforementioned Media page translated into Finnish.

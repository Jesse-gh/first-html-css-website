Welcome to my project!

This website is my first HTML and CSS project. The main purpose of this site is to document and explain how this website itself was built.

Project details:

  • Responsive Design: The website is fully responsive, meaning it scales dynamically and works seamlessly on both desktop computers and mobile devices.
  • Technologies: It is built using purely HTML and CSS. No advanced frameworks were used, as this project was created for the "Explore the fundamentals of HTML and CSS" course at the South-Eastern Finland University of Applied Sciences (XAMK).
  • Website Structure: The site consists of six pages in total:
    • A basic homepage in English (this page).
    • The basic homepage translated into Finnish.
    • A detailed, technical version of the English homepage aimed at IT professionals.
    • The technical version translated into Finnish.
    • A separate Media page showcasing an image gallery and an embedded YouTube video in English.
    • The Media page translated into Finnish.

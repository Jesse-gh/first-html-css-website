Technical Details

This page provides a deeper dive into the technical architecture and the specific features used to build this portfolio project.

Advanced Features & Design Choices:

  • CSS3 Transitions & Tooltips: One example of how CSS3 was used is the custom tooltips on the navigation and footer links. They utilize the opacity property combined with a transition delay (0.3s) to create a smooth, user-friendly fade-in effect when hovered over.
  • Advanced Flexbox Logic: The navigation bar uses a sophisticated three-column Flexbox structure. It features a spacer element that dynamically pushes the navigation links to the left on narrower screens, ensuring the layout remains intact without overlapping the language toggle button.
  • Transparency & Backgrounds: The site employs a full-page background image fixed to the viewport. The main content container uses an rgba() background color to create a semi-transparent effect that allows the background image to subtly show through while maintaining perfect text readability.
  • Iframe Image Gallery: The image gallery on the media page is built using an HTML iframe element. By linking the thumbnail anchors directly to the iframe's name attribute, clicking a thumbnail updates the main image dynamically without requiring a full page reload.
  • Custom Favicon: A favicon is the small image/icon displayed on the left side of the tab's title text (for example, in the Firefox browser). It's blue and features my initials, JH. I created the favicon myself and it was harder than expected, because the rounded corners weren't easy to make transparent, so it took some extra Photoshop skills to get it done.

Backend Architecture:

As a deliberate design choice, this website does not utilize a backend database. The architecture was kept intentionally static and simple to focus purely on the core fundamentals of front-end web development (HTML & CSS).

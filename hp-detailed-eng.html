Technical Details

This page provides a more detailed look at the technical architecture and other special features used in building this project. Tips from W3schools were used to some extent as a source of inspiration for creating this site.

Design Choices and Features:

  • Responsiveness/Scalability: Initially, I had issues when the browser window was made narrower. The language switch button on the navigation bar could overlap with the link named "Media". However, I managed to fix this by dividing the navigation in a more logical way. Now, when scaling, only the language switch button is allowed to push the other navigation bar texts to the left, but not the other way around. The navigation bar texts cannot push the language switch button away or force it onto another line.
  • CSS3: One example of using CSS3 is the tooltips for the language switch button and the footer's LinkedIn link. The tooltips appear when the user hovers the mouse over the links. A 0.3-second delay has also been set to them so they don't appear immediately.
  • Image gallery built with iframe technology: The image gallery on the Media page is built using an iframe element. Thanks to the links on the thumbnails (miniature versions of the images), clicking a picture updates the new image on the screen without having to reload the entire page.
  • Favicon and background image: A background image has been set for the site, which changes depending on whether the page is in English or Finnish. Additionally, a favicon was created for the site using Photoshop. A favicon is a small icon that appears on the left side of the browser tab's title text (for example, in the Firefox browser). It can be recognized by its blue color and my initials, JH. I created the favicon myself, and it was harder than expected because the square's rounded corners weren't easy to make transparent, so making it required a bit of tweaking in Photoshop.

Technologies intentionally not used:

  • As a conscious choice, the site does not use a database. I deliberately, and following the course instructions, decided not to use any programming languages or frameworks other than HTML and CSS languages. I wanted to keep the structure clean and simple so that the core features of these languages could properly stand out.

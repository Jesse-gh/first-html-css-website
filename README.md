# HTML & CSS Website by Jesse H

## About the Project
This is my first larger solo website project using only HTML and CSS languages. The website's purpose is to explain how the webpage itself was made. My goal was to show my understanding of web technologies. I did not use any pre-made templates or frameworks for this project.

Creating this website was originally part of a University of Applied Sciences project. As suggested during the course, I frequently used W3Schools as a source of inspiration and for trying out new features. Since this was my first larger solo web project and the course had a pass/fail grading system, I intentionally kept the project size and the number of features small. I plan to build larger and more complex projects in the future.

The website is hosted on GitHub Pages. You can try it out here:<br>
https://jesse-gh.github.io/first-html-css-website/

## Technologies & Tools Used
* HTML5
* CSS3
* Visual Studio Code
* Git and GitHub
* Image editing (Photoshop)

## Features & Technical Details
* **Strictly HTML & CSS:** No pre-made templates or layouts were used. All styling is handled via a single external CSS file which sets the styles for all of the six HTML pages.
* **Responsive Design:** The site's responsiveness works well on normal computers and cell phones. For scaling, the navigation and layout utilize CSS Media Queries and Flexbox.
* **Bilingual Content:** The site is available in both English and Finnish. The background image changes based on the selected language.
* **Interactive Elements:** Features custom CSS tooltips and an interactive image gallery built using iframe technology.
* **Development Environment:** The website was developed in Visual Studio Code, utilizing the Live Server extension for local testing.
* **Version Control:** Git was used for version control throughout the development process, and the project repository is hosted on GitHub.
* **Testing:** All HTML and CSS code has been checked with W3C validators. All warnings and errors were fixed during the testing phase. The website's functionality was also tested on Windows 11 using Chrome, Edge, and Firefox browsers, and the mobile version was tested on an iPhone using Safari.
